# EDA-Loan-Approval-Dashboard
📊 Project Overview
- An interactive Power BI dashboard analyzing
- 101 loan applications to identify approval drivers.

🛠 Tools Used
- Power BI Desktop
- Power Query (Data Cleaning)
- DAX (Calculated Measures)

📈 Key Insights
- 67% overall loan approval rate
- Credit History = #1 approval driver
- Most loans = 360 month term

📁 Files
- .pbix = Power BI dashboard file
- .csv = cleaned dataset
